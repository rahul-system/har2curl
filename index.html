HAR to curl

Turn a network log (.har) from a BrowserStack App Live session into curl commands you can paste into a bug ticket. Your file stays on your computer. Nothing is uploaded.

How to use
  1. In your BrowserStack App Live session, download the network logs as a .har file.
  2. Drop that file in the box below (or click it to choose the file).
  3. Type part of the URL you care about in the filter box, e.g. leadsquared.com or Leads.Get.
  4. Keep Hide secrets ticked, then click Copy on a request and paste it into your ticket.

Red badges (4xx / 5xx) are requests that failed. They're usually the ones to report.
